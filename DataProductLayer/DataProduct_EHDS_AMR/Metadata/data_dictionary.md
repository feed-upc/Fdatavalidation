# EHDS AMR Data Product — Data Dictionary

## Overview

This data product contains **synthetic data** for the European Health Data Space (EHDS) antimicrobial resistance (AMR) surveillance use case. The data is structured according to the EHDS data model (see `UML.png`) and contains **intentional, deterministic quality violations** to test six Data Quality Requirements (DQR1EH–DQR6EH).

All data is generated by `Code/generate_synthetic_data.py` with a fixed random seed (`--seed 42`) to ensure exact reproducibility.

---

| `resistancePercentage` | Decimal | Resistance percentage (suppressed if n < 10)        | —            | —          |

### Sample Size Distribution

- **~5%** of specimens: n < 10 (flagged `SUPPRESS`)
- **~10%** of specimens: 10 ≤ n < 30 (flagged `TRUE`)
- **~85%** of specimens: n ≥ 30 (adequate)

## Quick Verification

```python
import pandas as pd

patients = pd.read_csv('Data/Patient_Summary.csv')
pregnancies = pd.read_csv('Data/Pregnancy_History.csv')
isolates = pd.read_csv('Data/Isolate.csv')

# DQR1EH: NULL patient IDs
assert (patients['nationalHealthcarePatientID'] == '').sum() == 5

# DQR3EH: Males with pregnancy records
male_ids = set(patients[patients['gender'] == 'M']['nationalHealthcarePatientID'])
male_pregnancies = pregnancies[pregnancies['patientID'].isin(male_ids)]
assert male_pregnancies['patientID'].nunique() == 5

# DQR4EH: Total isolates ≥ 2000
assert isolates['nIsolates'].sum() >= 2000
```
